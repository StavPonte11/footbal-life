# UI/UX Development Skill

## Product philosophy

The UI should communicate:

> "This is my footballer's life."

Not:

> "I am managing a football database."

## Mobile first

Design for portrait mobile screens.

Prioritize:

- touch targets
- readability
- hierarchy
- quick actions
- short sessions

## Information hierarchy

Every screen should answer:

1. Where am I?
2. What is happening?
3. What can I do?
4. What happens next?

## Primary action

Each screen should have a clear primary action.

Avoid presenting ten equally important buttons.

## Reusable components

Prefer consistent:

- cards
- player headers
- attribute bars
- match cards
- event cards
- relationship cards
- navigation
- CTA buttons

## Narrative UI

Life events should feel like moments in the player's story.

Do not expose raw numerical consequences everywhere.

Prefer:

> "Your manager seems disappointed."

over:

> Manager trust -7

Numbers can still exist where useful.

## Football vs life

Football screens and life screens can have different moods while maintaining the same overall design system.

## Mockups

When creating mockups, prioritize:

- information architecture
- visual hierarchy
- interaction flow
- consistency

Do not begin with implementation details.
